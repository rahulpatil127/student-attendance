# Student Attendance Management System — Agent Handoff Pack

This pack contains the product context, architecture, engineering rules, implementation plan, and supporting technical documents for an agent to build the application.

## Start here
1. Read `ai-contax/context.md`.
2. Read `ai-contax/architecture.md`.
3. Follow `ai-contax/rules.md`.
4. Execute `ai-contax/software-development-plan.md` phase by phase.
5. Track decisions in `docs/decisions.md`.

## Confirmed stack
React.js + Vite + JavaScript, Tailwind CSS, Django REST Framework, SQLite, Django session authentication, and Django-managed password hashing (bcrypt-compatible configuration if required).

## Important
This is a specification and implementation plan, not the completed application. The agent must implement, test, document, and verify all acceptance criteria before claiming the product is ready.
